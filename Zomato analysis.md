# Zomato Order & Restaurant Analysis Using Power BI & SQL

## 📌 Project Overview
This project performs an end-to-end data transformation, aggregation, and visualization analysis on **Zomato's Order and Restaurant datasets**. The analysis cleans raw operational data using **SQL**, models data relationships, and visualizes customer purchasing patterns, restaurant performance, and regional revenue metrics in **Power BI**.

---

## 🛠️ Tech Stack & Skills
* **Database & Transformation:** MySQL (Data Cleaning, Aggregations, Joins, CTEs, Views)
* **Business Intelligence:** Power BI (Data Modeling, DAX, Interactive Dashboarding)
* **Domain:** Food & Beverage, Business & Marketing Analytics

---

## 📊 Business Use Cases & Tasks Covered
1. **Restaurant Distribution by City:** Bar Chart / Map analyzing restaurant density per city.
2. **Order Distribution:** Pie Chart breaking down percentage of total orders across cities.
3. **Order Trends Over Time:** Line Chart visualizing seasonal sales spikes and peak demand hours.
4. **Rating Correlation Analysis:** Scatter plot & matrix exploring impact of pricing and delivery speed on ratings.
5. **Top 5 Revenue Generating Restaurants:** Column Chart highlighting top-earning partners.
6. **Area Revenue Breakdown:** Treemap illustrating locality-wise revenue contributions.
7. **City Order Density:** Heat map pinpointing supply-demand gaps across target locations.
8. **Executive KPIs:** Total Revenue, Average Order Value (AOV), and Total Orders.
9. **Restaurant Sales Performance Table:** Detailed summary table with dynamic filtering and conditional formatting.
10. **Interactive Power BI Dashboard:** Unified multi-page presentation report.

---

## 🚀 How to Run the SQL Script
1. Clone this repository or download `Zomato_Analysis_Transformation.sql`.
2. Open **MySQL Workbench** or any SQL IDE.
3. Import the raw CSV files (`Zomato_Restaurants.csv` and `Zomato_Orders.csv`).
4. Execute `Zomato_Analysis_Transformation.sql` to clean the data, run analytical queries, and generate the final transformed view (`Zomato_Transformed_View`).
5. Load the transformed view or exported file into **Power BI** for dashboard generation.
